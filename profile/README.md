CloudForge Labs

Build. Break. Learn. Repeat.

CloudForge Labs is a personal cloud engineering lab focused on building, automating and understanding cloud infrastructure through hands-on experimentation.

The goal is simple: turn ideas into working infrastructure, explore how things work under the hood, and document the process along the way.

Areas of Focus

- Infrastructure as Code — Terraform-first infrastructure provisioning and management.
- Cloud Platforms — AWS initially, with Azure and Google Cloud exploration planned.
- Automation & Integration — Serverless applications, APIs and cloud-native workflows.
- Contact Centre Engineering — Amazon Connect, integrations and advanced routing solutions.
- Architecture & Security — Scalable designs, identity, permissions and cloud best practices.

Engineering Philosophy

- Infrastructure should be reproducible, version-controlled and documented.
- Understand the technology, not just the deployment steps.
- Experiment, troubleshoot and learn from failures.
- Build practical solutions to real engineering problems.

Current Focus

Establishing the CloudForge foundation using Terraform, AWS IAM Identity Center and GitHub.

The first milestone is provisioning and managing a dedicated AWS lab account entirely through Infrastructure as Code.
